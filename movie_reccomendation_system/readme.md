# 🎬 Movie Recommendation System

An intelligent movie recommendation system built using machine learning and data analysis techniques.  
It suggests movies based on user preferences, content similarity, and collaborative patterns.

---

## 🚀 Features

- 🎯 Personalized movie recommendations  
- 🧠 Content-based filtering using cosine similarity  
- 🤝 Collaborative filtering (optional hybrid version)  
- 📊 Data preprocessing and feature engineering  
- 💾 Pickle model (`similarity.pkl`) for fast predictions  
- 🖥️ Streamlit / Flask web interface for interactive use
